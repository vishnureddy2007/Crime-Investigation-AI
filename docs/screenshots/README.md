# Screenshots

The PNGs in this directory are **labelled mockups**, not captures of a
running Streamlit session. They were generated by
`scripts/render_demo_screenshots.py` (Pillow-only, no Playwright) to
give the GitHub-rendered `docs/USER_MANUAL.md` visual anchors on a
machine that has no live `streamlit run app.py` available.

Each mockup shows:
- the **CRIMEVISION AI** wordmark in the sidebar,
- the page's real title and subtitle as it appears in the live UI,
- a 4-tile KPI strip sized to match the live dashboard,
- a body panel with the page's typical content (severity, observations,
  detection counts, etc.),
- a yellow **"DEMO SCREENSHOT (mockup)"** ribbon so they cannot be
  mistaken for live captures.

## Capturing real screenshots

See [`docs/USER_MANUAL.md`](../USER_MANUAL.md), section
**"Capturing real screenshots"** for a 5-line recipe:

1. Launch the app: `streamlit run app.py`.
2. Open the page you want in your browser.
3. Drop a representative file into the uploader (if the page needs
   one) and run the analysis.
4. Use your OS screenshot tool (Windows: `Win+Shift+S`,
   macOS: `Cmd+Shift+4`, Linux: `gnome-screenshot`) to capture the
   browser window.
5. Save the PNG into this directory using the same slug
   (`dashboard.png`, `evidence_analysis.png`, etc.) to overwrite the
   mockup with a real capture.

The render script can be re-run any time to regenerate the mockups:

```bash
python scripts/render_demo_screenshots.py
```
